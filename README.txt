CITIZEN ASSIST - UPDATED WEBSITE

Purpose:
Citizen Assist is an independent educational project for “Assisting Citizens in Using Government Digital Portals.”

Included features:
- Citizen Assist logo with cropped/visible presentation in header and footer
- Government-portal-inspired header and navigation structure without copying another department's branding/content
- Home, Services, Guide, FAQ, About and Contact views
- Service search and category/difficulty filters
- PAN, Aadhaar, Passport and Driving Licence guides using the project's existing service data
- Documents checklist and step-by-step progress tracker
- Official portal buttons that open external government destinations
- English / Hindi / Marathi interface language switching
- Accessibility panel: font size, saturation, screen reader, high contrast, basic HTML view and invert colors
- Print button and skip-to-main-content control
- Mobile navigation
- Improved chatbot with different replies for greetings, thanks and service questions
- Footer with project information and quick links

Important:
Citizen Assist is NOT an official government website. Users should complete actual applications only on official government portals.

To run:
1. Extract the ZIP.
2. Open Citizen-Assist/index.html in a modern browser.
3. An internet connection is needed for Font Awesome icons.
